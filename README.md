# Anisotropic Calderón problem: comparator challenge  

Comparator challenge for the main theorem of
[*Smooth anisotropic uniqueness in the Calderón problem from one boundary patch*](https://github.com/openai/math/blob/main/preprints/Smooth-Anisotropic-Uniqueness-in-the-Calderon-Problem-from-One-Boundary-Patch-September-24-2026/paper.pdf)
(OpenAI, September 24, 2026), from the [OpenAI math repository](https://github.com/openai/math), specialized to
`n = 3`, `M` the closed unit ball, `Γ = ∂M`, and metrics Euclidean outside the unit
ball.

- Comparator config: `ComparatorChallenges/AnisotropicCalderon.json`
